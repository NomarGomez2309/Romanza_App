# Prototipo Flutter conservado

Código anterior al reinicio de Romanza, conservado como referencia. No forma
parte del arranque ni del análisis de la aplicación activa. Sus importaciones
`package:romanza/...` corresponden a su ubicación original y no se mantienen.
`pubspec.yaml.reference` conserva las dependencias anteriores; no es un paquete
independiente ni un punto de entrada ejecutable.
