# Base visual Flutter

La guía anterior ya no existe en este repositorio. Esta base utiliza Material 3
y el tema estándar de Flutter; no define aún una identidad visual de producto.
La pantalla de arranque comparte un margen de 24 y una separación de 16 puntos.
Estados implementados: progreso, error con reintento y pantalla vacía de producto.
No hay módulos funcionales ni componentes personalizados duplicados.
