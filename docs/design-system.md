# Base visual Flutter

Esta rama conserva Material 3 estándar para las pantallas funcionales mínimas de
cuenta y pareja: márgenes 24, separaciones 16 y ancho máximo de 480 en el acceso.
No introduce una propuesta de marca nueva ni reemplaza las grillas aprobadas.

La implementación visual definitiva de Romanza (Fredoka/Nunito, Lucide, paletas y
panel de configuración) se incorporará sobre estos servicios en una fase propia.
El dashboard actual es un inicio mínimo de pruebas, no el dashboard de producto.
