No se asignó una nueva pareja de colores ni se modificó el generador. Falta aprobar una variante bicolor para Custom si se desea; no se fuerza Default/Forest/Neo sobre una paleta personalizada.

## Limitaciones y estado de publicación

Esta base aún no tiene perfiles conectados ni fotos de avatar reales; utiliza reservas gráficas. No es posible certificar fotografías de cuentas reales ni su sincronización aquí. El componente acepta imágenes sin sustituirlas y las pruebas verifican la geometría/fallback, pero no se afirma una validación de cuentas que no existen. No se añadieron las iniciales, ilustraciones ni datos del paquete.

No se compiló iOS desde Windows ni se certificó VoiceOver/TalkBack hablado. Los tamaños de referencia se validaron con Flutter, y Android además en hardware. Gradle conserva una advertencia del entorno sobre versiones de XML de Android SDK.

**Código preparado en rama local; compilación debug instalada en el Pixel. No desplegado en producción.** No existe pipeline, fastlane ni flujo de release documentado en este checkout. Android release sigue configurado con firma debug; no se generó una versión de tienda ni se cambiaron firma, splash, launcher, identificadores o servicios remotos. La rama remota carece de cinco commits de base local; no se deben presentar todos esos cambios como si fueran únicamente este encabezado.

Antes de publicación real: integrar/revisar la base Romanza/Dart correcta, revisar este diff limitado, configurar la firma/canal de distribución por el flujo que defina el proyecto y verificar el artefacto en ese entorno. Una instalación local no prueba ese despliegue.
